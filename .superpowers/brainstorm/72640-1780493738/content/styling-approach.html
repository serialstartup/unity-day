Styling Yaklaşımı

Uygulamanın temel stil sistemi nasıl kurulsun? Tasarım dosyalarındaki renk paleti ve tipografi bunun üzerine inşa edilecek.

A

NativeWind v4 (Tailwind CSS)

React Native'de Tailwind class'larını kullan. HTML mockup'larındaki CSS değişkenlerini Tailwind token'larına çevirmek kolay. className="bg-primary text-white rounded-2xl" gibi kullanım.

Artıları

  • Web mockup'larına en yakın syntax
  • Hızlı prototipleme
  • Dark mode desteği kolay

Eksileri

  • Ekstra bağımlılık
  • Expo v56 ile config gerektirir
B

React Native StyleSheet

Standart RN yaklaşımı. Merkezi bir theme.ts dosyasında renkler ve spacing token'ları tanımlanır, component'lar StyleSheet.create ile kullanır.

Artıları

  • Sıfır ekstra bağımlılık
  • En stabil yaklaşım
  • RN'in doğal dili

Eksileri

  • Daha fazla boilerplate
  • Web mockup'larından çeviri zahmetli
C

Tamagui

TypeScript-first UI kit. Kendi design token sistemi var, animasyon desteği güçlü. Önceden hazır component'lar (Button, Input, Card) ile hızlı başlangıç.

Artıları

  • Hazır component kütüphanesi
  • Güçlü animasyon ve theme sistemi
  • Cross-platform uyumluluk

Eksileri

  • Öğrenme eğrisi yüksek
  • Büyük bundle size
  • Custom tasarıma uyarlamak zaman alır

💡 Öneri: NativeWind v4 — HTML mockup'larındaki Tailwind-benzeri yapı doğrudan uygulamaya taşınabilir, design sistemi tutarlı kalır.
